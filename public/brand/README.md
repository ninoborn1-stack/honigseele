# Marke

- `logo.svg` – Original-Logo für hellen Grund (kommt von Anna)
- `logo-light.svg` – Variante für dunklen Grund (Intro, Mails, dunkle Flächen)

Danach in `content/brand.json` unter `logo.src` / `logo.srcLight` eintragen, Breite/Höhe ergänzen und `placeholder` auf `false` setzen.
Das Logo wird nie verzerrt, umgefärbt oder animiert – animiert wird nur die Blume des Lebens.
